# 候选网段可用性检查

入口：子网清单 → 最上方第三个圆形靶心按钮 → 网段可用性。该按钮在打开和保存规划项目按钮右侧，不是编辑区下方的清单检查按钮。小窗口中页签可能需要左右滚动。

当前清单作为占用记录。输入完整 IPv6 CIDR，点击检查图标或按 Enter。候选地址可含主机位，自动规范化；清单所有记录必须有效。允许空清单，不相交的记录不影响候选，不要求清单中所有记录位于候选内。

## 示例

当前清单：

```text
# 已占用
2001:db8::/126
2001:db8::10/124
2001:db8::2/127
```

候选输入 `2001:db8::/125`。候选包含 8 个地址，冲突原始行号为 2 和 4，占用并集为 4 个地址，空闲为 4 个，状态为“部分占用”。空闲 CIDR 是 `2001:db8::4/126`，占用 CIDR 是 `2001:db8::/126`。第 3 行与候选不相交，不计为冲突。

## 输出与保留规则

上方复制／保存按钮输出完整报告，含原始冲突记录和候选内全部空闲／占用范围。下方类别可选“候选内空闲 CIDR”或“候选内占用 CIDR”，旁边按钮仅复制或保存所选类别的纯 CIDR，支持重新导入清单；不提供自动占用或追加。无结果或超过 5,000 条时禁止输出空清单或不完整清单，完整报告仍可保存。

修改输入立即清除旧结果；保存期间输入、结果或类别改变会中止旧结果保存。报告依界面语言输出，沿用覆盖确认和目标文件冲突保护。

弹窗使用打开时的当前清单快照。关闭后修改原清单，再重新打开以刷新基准。查询输入、输出类别和报告不保存到规划项目 JSON，需要留存时请单独保存报告或 CIDR TXT。“空闲”仅是相对于录入清单的数学结果，不表示实际网络未使用或可直接部署。
