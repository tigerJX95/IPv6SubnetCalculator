# 关于与网站链接

点击主窗口右上角“ⓘ”关于图标，或按 F1。窗口参考 UnattendLocal 的信息分类，沿用本项目 PyQt 界面、实际版本和许可证，不复制其他项目的许可声明。可使用右上角关闭按钮或 Esc；页面不再提供重复关闭或全页复制按钮，文字仍可选中复制。

| 页面／设置 | 内容 | 示例 |
|---|---|---|
| 程序信息 | 图标、实际版本、项目网站、功能、版权、致谢及运行组件版本 | 显示 V1.17 与实际运行 Qt 版本 |
| 项目主页 | 可选择复制的 HTTPS 超链接，点击时交给系统默认浏览器 | `https://github.com/tigerJX95/IPv6SubnetCalculator` |
| 下载正式版 | 指向 Releases 的超链接，供下载发布的 EXE | `https://github.com/tigerJX95/IPv6SubnetCalculator/releases` |
| 使用说明 | 随程序打包的离线帮助，跟随界面语言 | 查看批量候选输入与结果边界 |
| 第三方许可下拉框 | 组件概览、项目 GPL、NOTICE、PyQt6、Qt、中文控件翻译和 SIP 许可原文 | 选择“Qt 6 · LGPL v3 原文” |
| 法律责任 | 数学计算边界、部署责任、开源权利及无担保声明 | 查看“无担保”条款 |

![中文版关于窗口](screenshots/about_zh_CN_light.png)

窗口跟随浅深色主题和当前语言；切换语言保留当前页面及许可选择。许可原文保持原始语言。打开窗口、切换语言或主题均不启动浏览器；只有点击有效 HTTPS 链接才打开，禁止通过文档链接执行本地文件或脚本。浏览器启动失败时，悬停提示提供可复制的地址。
