# 批量网段可用性检查

入口：子网清单 → 顶部第三个圆形靶心查询按钮 → 批量可用性。小窗口中可左右滚动页签。当前清单作为占用基准，窗口使用打开时的快照；需要刷新基准时，关闭窗口、修改清单后重开。

## V1.17 输出类别

下方类别影响其右侧的 CIDR 复制／保存按钮；上方报告复制／保存仍输出全部候选的完整报告。输出为完整候选网段，**不是候选中的空闲或占用片段**。

| 类别 | 筛选条件 | 基准 `::/127`，候选 `::/126`、`::4/126`、`::/127` 的输出 |
|---|---|---|
| 全部空闲 | 占用地址数为 0 | `::4/126` |
| 部分占用 | 占用和空闲地址数均大于 0 | `::/126` |
| 全部占用 | 空闲地址数为 0 | `::/127` |
| 存在占用冲突 | 占用地址数大于 0，包含部分和全部占用 | `::/126`、`::/127` |
| 全部候选 | 不按占用状态筛选 | `::/126`、`::4/126`、`::/127` |

所有类别都先规范化，再去重，按首次输入顺序保留候选边界与包含项，不聚合、不重新分配。候选彼此重叠时仍不可视为可同时分配。切换类别不修改结果、原始输入或报告；保存对话框期间类别或结果变化会中止旧清单保存。无匹配候选时，纯 CIDR 按钮禁用，完整报告仍可保存。

## 设置与按钮

| 项目 | 用途与规则 | 示例 |
|---|---|---|
| 基准占用清单 | 使用主窗口当前清单；所有记录必须有效，允许空清单 | `2001:db8::/127` |
| 批量候选输入 | 每行一个完整 IPv6 CIDR；忽略空行和 # 注释，保留物理行号；主机位自动规范化 | `2001:db8::3/126` 规范化为 `2001:db8::/126` |
| 检查图标 | 校验两份输入后执行整批计算；任一错误拒绝整批，不输出部分成功结果 | 点击输入框下方检查图标 |
| 上方复制／保存图标 | 输出完整逐条报告，包含状态、容量、重叠候选数和规范化标记 | 保存 `IPv6_BatchAvailability.txt` |
| 输出类别 | 按所选占用状态输出候选 CIDR，规范化、去重，按首次输入顺序，保留包含项且不合并 | `::/125` 与 `::/126` 均保留 |
| 类别右侧复制／保存图标 | 输出纯 CIDR，可重新导入子网清单；所选类别为空时禁用 | 保存 `IPv6_free_candidates_CIDRs.txt` |

基准和候选分别限制为 5,000 条记录、1 MiB UTF-8 文本和 20,000 个物理行。单条 CIDR 不超过 200 字符。候选不能为空。IPv4、区域标识、非法前缀或缺失前缀均拒绝。

## 示例

基准清单输入：

```text
2001:db8::/127
```

批量候选输入：

```text
2001:db8::/126
2001:db8::4/126
2001:db8::/127
2001:db8::4/126
```

| 候选行 | 状态 | 占用／空闲地址数 | 与其他候选重叠的记录数 |
|---|---|---|---|
| 1 | 部分占用 | 2／2 | 1 |
| 2 | 全部空闲 | 0／4 | 1 |
| 3 | 全部占用 | 2／0 | 1 |
| 4 | 全部空闲 | 0／4 | 1 |

报告保留第 2、4 行重复记录；全部空闲候选纯 CIDR 输出为一条 `2001:db8::4/126`。

## 结果边界

每条候选独立对照基准清单，候选不会互相占用或预留。报告中的“重叠候选记录数”包含重复及包含关系，但不计相邻不重叠的候选，也不计自身。两条全部空闲候选可能重叠，不能据此同时分配；重叠候选的地址数不能相加。

报告不枚举地址，使用精确整数及占用并集；不相交的占用记录不影响候选。修改候选立即清空结果；保存期间输入或结果变化会中止旧输出。保存沿用覆盖确认和外部文件冲突保护。

不修改基准清单，不自动分配或追加；候选输入和结果不写入规划项目 JSON，需要保留时单独保存。空闲仅相对于基准清单，不说明真实网络状态、地址分配权或实际可部署性。
