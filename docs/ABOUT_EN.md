# About and Website Links

Click the upper-right About information icon or press F1. The information grouping follows UnattendLocal while preserving this application's PyQt interface, actual version and license. Close with the title-bar close button or Esc. Duplicate footer close and whole-page copy controls are omitted; text remains selectable for copying.

| Page/control | Contents | Example |
|---|---|---|
| Program Information | Icon, actual version, project links, features, copyright, acknowledgments and runtime component versions | V1.22 and the actual Qt runtime version |
| Project home | Selectable HTTPS hyperlink; opens the system default browser when clicked | `https://github.com/tigerJX95/IPv6SubnetCalculator` |
| Download releases | Hyperlink to Releases for published EXE downloads | `https://github.com/tigerJX95/IPv6SubnetCalculator/releases` |
| Release Notes | Current version changes, separate from operating instructions; follows interface language | Shows V1.22 only |
| User Guide | Bundled offline help following the interface language | Batch candidate inputs and result boundaries |
| License selector | Component overview, project GPL, NOTICE, PyQt6, Qt, Chinese widget translations and SIP originals | Select the Qt 6 LGPL v3 original |
| Legal Information | Calculation limits, deployment responsibility, open-source rights and warranty disclaimer | Read the warranty disclaimer |

![English About window](screenshots/about_en_US_light.png)

The window follows the active light/dark theme and language; changing language retains the selected tab and license. License originals retain their original language. Opening the window or changing language/theme never starts a browser. Only explicit clicks on valid HTTPS links open it; local-file and script links cannot execute through the document. A failed browser launch provides the address in a tooltip for manual copying.

The User Guide explains operations. The separate Release Notes tab shows only the current V1.22 changes. Main document titles are centered, with spacing before subheadings; original license wording remains intact.
